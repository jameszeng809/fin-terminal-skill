# fin-terminal-skill

> 用 AI 把彭博终端的专业能力，变成人人用得起的投研助手。

## 一键安装

通过 WorkBuddy / CodeBuddy Skill 市场导入，或手动将本仓库克隆到 Skills 目录。

```bash
# 方式一：SkillHub 一键导入（推荐）
# 访问 https://skillhub.cn 搜索 "fin-terminal"

# 方式二：手动克隆
git clone https://github.com/jameszeng809/fin-terminal-skill.git ~/.workbuddy/skills/fin-terminal
```

## 快速开始

安装后，直接在 AI 对话中输入：

```
分析贵州茅台（600519），生成投研报告
```

AI 将自动调用本 Skill，完成：

```
✅ 已确认：贵州茅台（600519.SH），白酒行业

[数据聚合中...] → 获取实时行情、财务数据、近期新闻
[指标计算中...] → ROE 34.0% | PE 28.5x | 毛利率 91.7%
[可比公司筛选中...] → 匹配五粮液、泸州老窖、洋河股份...
[图表生成中...] → K线图 ✓ | 对比柱状图 ✓ | 雷达图 ✓
[报告导出中...] → HTML 交互式报告已生成

📋 报告已生成，正在预览...
```

## 核心功能

| 功能模块 | 说明 |
|---------|------|
| **行情速览** | 实时股价、涨跌幅、成交量、市值 |
| **财务透视** | 自动拉取三大报表，计算 ROE/PE/PB/毛利率 |
| **可比公司** | 自动筛选同行业对标公司，横向对比估值 |
| **K线图表** | 交互式 K 线图（含成交量），支持多周期 |
| **雷达图评分** | 盈利/成长/估值/风控/营运/现金流 六维评分 |
| **HTML投研报告** | 一键输出完整报告（含图表），可直接分享 |

## 技术特点

- **多数据源聚合**：优先调用 `westock-data` 和 `neodata-financial-search` Skill，回退至 WebSearch
- **零 API 成本**：所有数据通过公开渠道获取，无需付费 API Key
- **智能降级**：mplfinance 不可用时自动降级为 matplotlib 折线图
- **中国颜色规范**：涨 → 红色，跌 → 绿色
